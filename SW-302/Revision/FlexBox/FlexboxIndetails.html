9. The Famous Centering Problem - SOLVED!

The Old Problem: "How do I center a div?" was one of CSS's biggest challenges. Flexbox makes it trivial!
.center-container { display: flex; justify-content: center; /* horizontal */ align-items: center; /* vertical */ height: 200px; }

Perfectly Centered!

Both horizontally and vertically!
